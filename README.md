# 长沙摩托车通行提醒地图｜完整可接手版

这是一个静态网站项目：不用后端、不用数据库，部署到 GitHub Pages 即可分享链接。

## 当前定位

合规名称建议：**长沙摩托车通行提醒地图**。

不要使用“躲电子眼、逃避抓拍、绕开执法、扣分地图”等表达。页面应始终强调：遵守交通法规，以官方通告、现场交通标志和交警实际管制为准。

## 已实现功能

- 高德地图模式：填入高德 Web端 JS API Key 后自动启用。
- 无Key预览模式：没有Key时也能显示近似区域、点位、筛选和列表，便于你先看效果。
- 禁摩合围区域近似多边形。
- 官方边界道路近似线。
- 官方边界提示点、重点边界道路点、跨江桥隧入口复核点。
- 点位搜索、分类筛选、统计、移动端侧栏。
- 点击点位弹窗：类型、来源、可信度、备注、更新时间。
- 一键打开高德查看/导航到该点。
- 路线风险粗测：输入起点终点，检测直线附近的已录入风险点和是否穿过禁摩合围区。
- 点位录入助手：`admin.html`。
- 用户投稿CSV模板：`data/user-reports-template.csv`。
- Codex接手说明：`docs/CODEX_HANDOFF.md`。

## 数据来源

种子数据主要来自公开资料：

1. 长沙市公安局交通警察支队《关于市区部分区域道路禁止摩托车通行的通告》（长公交发〔2025〕04号）。
2. 红网/潇湘晨报对2025年通告的报道。
3. 长沙本地宝对限行区域和施行时间的汇总。

官方通告核心范围：

> 禁止摩托车在北二环、岳麓大道、麓谷大道、枫林路、麓景路、梅溪湖北路、西二环、南二环、湘江路、绕城高速、京港澳高速、香樟路、新花侯路、长沙大道、京港澳高速、汽配城路、锦绣路、福元路、芙蓉北路合围区域内的道路通行，包括边界道路。绕城高速、京港澳高速除外。

## 运行方式

### 1. 直接预览

打开：

```text
preview.html
```

这个页面不需要高德Key，适合你先看大概效果。

### 2. 正式地图运行

打开：

```text
js/config.js
```

把：

```js
amapKey: "YOUR_AMAP_JS_KEY"
```

换成你的高德 Web端 JS API Key。

然后本地运行：

```bash
cd changsha-moto-map-full
python -m http.server 8080
```

浏览器打开：

```text
http://localhost:8080
```

### 3. GitHub Pages部署

1. 新建GitHub仓库。
2. 上传本项目所有文件。
3. Settings → Pages。
4. Source选择 `Deploy from a branch`。
5. Branch选择 `main`，目录选择 `/root`。
6. 等待公开链接生成。

## 正式发布前必须做

- 用高德拾取坐标修正 `data/zones.json` 里的边界线。
- 用实拍照片/官方公告/多源交叉验证补充电子眼点位。
- 未验证点位必须标记为 `camera_unverified` 或 `user_report`。
- 检查页面文案，避免“规避执法”表达。
- 加一个明显的“非官方数据”免责声明。
